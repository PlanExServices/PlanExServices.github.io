Security Policy — DelQuro - Bravo

Reporting a Vulnerability

If you discover a security vulnerability in DelQuro - Bravo, please report it privately via email to security@delquro.app or open a confidential advisory on GitHub.

Supported Versions

Version Supported
v1.0.x Yes

$0 Security Controls

  • Runtime security headers (X-Frame-Options, X-Content-Type-Options, CSP) in src/middleware.ts.
  • Strict Zod validation on every API endpoint.
  • Parameterized SQLite queries via better-sqlite3.
  • SSRF allowlist protection via isSafeUrl().
