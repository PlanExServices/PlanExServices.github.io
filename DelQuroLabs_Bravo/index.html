DelQuro — Bravo (v1.0)

The App Building Assistant — “Build Apps with Your Brain, Not Syntax”

What Was Built

DelQuro — Bravo (v1.0) is an intuitive, visual, and natural-language application architect and blueprint generator built on Next.js 16 App Router, React 19, TypeScript, and Tailwind CSS. Users describe what they want to build in plain English (“with their brain, not coding”), and DelQuro generates:

  1. Structured App Specification: Core features, domain rules, and target audience.
  2. Interactive Live Component & Screen Preview: A live interactive sandbox rendering functional React 19 screens with instant desktop and mobile (375px) viewport toggle.
  3. TypeScript Component Code Blueprint: Exportable, production-ready TSX server/client components and Zod validation schemas.
  4. Local SQLite Persistence: Pre-seeded with 12 rich, categorized application templates stored in a local SQLite database (./data/local.db) with zero external DB servers required.

Who It Is For

  • Beginner Software Creators & Entrepreneurs: Turn product concepts into structured blueprints without struggling with boilerplate configurations.
  • Intro Developers & Rapid Prototypers: Explore Next.js 16 App Router architecture and copy clean TypeScript code snippets into real workspaces.
  • Full-Stack Educators: Teach modern web application architecture using interactive, offline-ready blueprints.

Core User Flow

  1. Explore & Select: Browse categorized application templates (/templates) across SaaS, Dev Tools, E-Commerce, and Content platforms.
  2. Describe Idea: Write a natural-language description of your application in the “Brain-to-App” architect form (/builder).
  3. Generate Blueprint: The local AI engine generates a modular three-tier specification (Frontend, Backend, Database).
  4. Interact Live: Click between generated screens in the Live Interactive Preview sandbox.
  5. Export & Starter Kit: Copy the TSX component code, download the JSON starter bundle, or download a complete standalone Next.js 16 project ZIP archive (/api/export-zip).
  6. Rate & Feedback: Submit thumbs up/down feedback to help calibrate the architecture engine.

Prerequisites & Exact Runtime Version

Fresh-Clone Quick Start

Verify that DelQuro — Bravo runs cleanly on any fresh machine:

git clone https://github.com/USER/delquro-bravo.git verify-app
cd verify-app
cp .env.test.example .env.local
npm ci
npm run build
npm test
npm run start

Open http://localhost:3000 in your browser. The app will boot immediately with pre-seeded categorized templates.

Architecture Overview

  • Presentation Layer: React 19 Server Components for high SEO performance on landing and template library pages; explicit 'use client' interactive widgets for the BlueprintViewer and AppBuilderWizard.
  • API & Validation Layer: Next.js 16 Route Handlers (/api/generate, /api/export, /api/export-zip, /api/feedback, /api/health) protected by sliding-window rate limiting and strict Zod input/output schemas.
  • Service Adapter Layer: Adapter Factory pattern (createAdapter) in src/lib/adapters/factory.ts. Automatically switches between fakeAI (deterministic offline mode) and realAI (live provider mode).
  • Persistence Layer: Local SQLite (better-sqlite3) in src/lib/db/index.ts with transparent fallback to :memory: for read-only containers.
  • Security & Headers: Runtime HTTP headers (X-Frame-Options: DENY, X-Content-Type-Options: nosniff, CSP) enforced in src/middleware.ts; SSRF validation via isSafeUrl().
