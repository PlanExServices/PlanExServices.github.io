DelQuro — Bravo (v1.0)

The App Building Assistant — “Build Apps with Your Brain, Not Syntax”

What Was Built

DelQuro — Bravo (v1.0) is an intuitive, visual, and natural-language application architect and blueprint generator built on Next.js 16 App Router, React 19, TypeScript, and Tailwind CSS. Users describe what they want to build in plain English (“with their brain, not coding”), and DelQuro generates:

  1. Structured App Specification: Core features, domain rules, and target audience.
  2. Interactive Live Component & Screen Preview: A live interactive sandbox rendering functional React 19 screens (Dashboard, Data Explorer, Settings) with mobile 375px viewport testing.
  3. TypeScript Component Code Blueprint: Exportable, production-ready TSX server/client components and Zod validation schemas.
  4. $0 Zero-Cost Local Persistence: Pre-seeded with demo blueprints (PromptForge AI, QueryCraft) stored in a local SQLite database (./data/local.db) with zero external DB servers required.

Who It Is For

  • Beginner Software Creators & Entrepreneurs: Turn product concepts into structured blueprints without struggling with boilerplate configurations.
  • Intro Developers & Rapid Prototypers: Explore Next.js 16 App Router architecture and copy clean TypeScript code snippets into real workspaces.
  • Full-Stack Educators: Teach modern web application architecture using interactive, offline-ready blueprints.

Core User Flow

  1. Explore & Select: Browse sample app blueprints from the pre-seeded local SQLite database or pick a quick template (PromptForge AI, QueryCraft, FocusFlow).
  2. Describe Idea: Write a natural-language description of your application in the “Brain-to-App” architect form.
  3. Generate Blueprint: The zero-cost AI engine generates a modular three-tier specification (Frontend, Backend, Database).
  4. Interact Live: Click between generated screens (Dashboard, Records Explorer, Settings) in the Live Interactive Preview sandbox.
  5. Export & Refine: Copy the TSX component code, download the JSON starter bundle, or refine the blueprint with natural-language instructions.
  6. Rate & Feedback: Submit thumbs up/down feedback to help calibrate the architecture engine.

Architecture Overview

  • Presentation Layer: React 19 Server Components for high SEO performance on landing and comparison pages; explicit 'use client' interactive widgets for the BlueprintViewer and AppBuilderWizard.
  • API & Validation Layer: Next.js 16 Route Handlers (/api/generate, /api/export, /api/feedback, /api/health) protected by sliding-window rate limiting and strict Zod input/output schemas.
  • Service Adapter Layer: $0 Adapter Factory pattern (createAdapter) in src/lib/adapters/factory.ts. Automatically switches between fakeAI (deterministic offline mode) and realAI (live provider mode).
  • Persistence Layer: Zero-cost local SQLite (better-sqlite3) in src/lib/db/index.ts with transparent fallback to :memory: for read-only containers.
  • Security & Headers: Runtime HTTP headers (X-Frame-Options: DENY, X-Content-Type-Options: nosniff, CSP) enforced in src/middleware.ts; SSRF validation via isSafeUrl().

Troubleshooting & Known Limitations

  • SQLite in Read-Only Environments: If deployed to a read-only serverless container without persistent disk storage, the database adapter automatically falls back to an :memory: SQLite database. Pre-seeded demo blueprints remain accessible, but new feedback will reset on container restart unless connected to an external DB (DATABASE_URL).
  • Demo Mode Banner: When AI_API_KEY is not present, the DemoBanner is visibly rendered at the top of the application to ensure transparency.
  • IP Address Trust Caveat: Rate limiting uses getClientIp() from x-forwarded-for. This header is only trusted when hosting behind a reverse proxy (Vercel, Netlify, Cloudflare). If self-hosting directly on internet-facing TLS without a proxy, treat getClientIp() as best-effort abuse control.
