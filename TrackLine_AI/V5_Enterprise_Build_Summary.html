1. Executive Overview

  • Reference & Concept: Rebuild of TrackLine AI v1.0 into an enterprise-hardened AI Video & Podcast Script Guardrail Studio.
  • Core User & Problem: Video creators and marketing teams suffer from tone drift, script bloat (>30s intros), and rule ignorance in generic LLM workflows.
  • Primary Workflow: Scripting with time-mapped beats (Hook, Intro, Content, Sponsor, CTA), live WPM duration math, automated 0–100 Retention compliance linting, and multi-format preview/export.
  • Privacy & AI Boundaries: Client-first storage with Zod schema validation; local deterministic engine works 100% offline ($0 / zero API key required); remote BYOK LLM engine connects to OpenAI (gpt-4o) and Anthropic (claude-3-5-sonnet) without server-side key logging.

2. Delivered Scope

  • Primary Vertical Slice:
    • Time-Mapped Beats Editor with live WPM calculation (120–190 WPM).
    • Guardrail Compliance Linter & 0–100 Retention Scorecard.
    • BYOK OpenAI / Anthropic API Client with graceful heuristic fallback.
    • 1-Click Multi-Platform Repurposing (TikTok Shorts, LinkedIn, Podcast Ads).
    • 3-Mode Studio Previewer (🎬 Video Storyboard, 🎙️ Voiceover, ⚡ Mashup).
    • Visual AI Storyboard Generator (16:9 cinematic frame synthesis).
    • Fullscreen Live Teleprompter (high-contrast #000 with spacebar auto-scroll).
    • Multi-Format Exporters (Markdown, JSON backup, PDF/Print Storyboard, and 1-Click Clipboard Copy).
  • Enterprise Hardened Core (trackline-pro/):
    • Zod schemas for Project, Segment, GuardrailRule, AuditResult.
    • Deterministic local adapter unit-tested with Vitest.
    • Browser storage service wrapped with SSR safety and schema corruption recovery.
