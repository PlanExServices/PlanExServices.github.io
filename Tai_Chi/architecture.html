Data Flow

Video Playback

User taps Play
    │
    ▼
VideoPlayer component
    │
    ├── Load video from CDN/cache
    │
    ├── Sync with AudioLayer
    │       │
    │       └── Play selected ambient track
    │
    └── Update progress via Zustand
            │
            └── Persist to localStorage

Practice Session

User starts timed session
    │
    ▼
SessionTimerStore initialized
    │
    ├── Load sequence moves
    │
    ├── Start timer
    │
    ├── For each move:
    │       │
    │       ├── Play video
    │       │
    │       ├── Show breathing cues
    │       │
    │       └── Auto-advance on complete
    │
    └── Session complete
            │
            └── Save to database

State Management

Global State (Zustand)

  • theme: dark light
  • playbackSpeed: 0.5 0.75 1 1.25 1.5
  • selectedAudioTrackId: string
  • audioVolume: number
  • isLooping: boolean
  • analyticsEnabled: boolean

Session State (Zustand)

  • isPlaying: boolean
  • currentTime: number
  • controlsVisible: boolean
  • currentMoveIndex: number

Server State (PostgreSQL via Drizzle)

  • User progress records
  • Favorites
  • Download records
  • Feedback submissions
  • Practice session history

Security Considerations

  1. No authentication - Reduces attack surface
  2. Local data only - No PII transmitted
  3. Session IDs - Random, non-identifiable
  4. Content URLs - Public CDN, no sensitive assets
  5. API routes - Health check only, no user data endpoints

Performance Optimizations

  1. Static content - Move/sequence data bundled at build time
  2. Image optimization - Next.js Image component
  3. Code splitting - Per-route bundles
  4. Video preloading - Metadata only until play
  5. Audio caching - Ambient tracks cached after first load
  6. Zustand persist - Instant hydration on load
