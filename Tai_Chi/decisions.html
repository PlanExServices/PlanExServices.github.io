ZenFlow - Technical Decisions

This document records key technical decisions made during the development of ZenFlow.

Architecture

Decision: Next.js instead of Expo

Rationale: The sandbox environment is configured for Next.js with PostgreSQL. Rather than fight the environment, we built a mobile-first responsive PWA that delivers an excellent mobile experience through the browser while enabling offline capabilities via service workers.

Trade-offs:

  • Pros: Single codebase, immediate deployability, SEO support, simpler development
  • Cons: Not native app, requires browser, some mobile features unavailable

Decision: PostgreSQL via Drizzle ORM for server-side data

Rationale: The environment provides PostgreSQL. We use it for tracking user progress, favorites, and sessions that could be synced across devices in the future.

Schema:

  • user_progress - Track watched moves and completion rates
  • user_favorites - Bookmarked content
  • user_downloads - Offline content tracking
  • user_preferences - App settings
  • user_feedback - Move clarity ratings
  • practice_sessions - Session history

Decision: Client-side state with Zustand + persistence

Rationale: For a meditation app, immediate responsiveness is critical. Zustand with localStorage persistence provides instant UI updates without round-trips.

Decision: Static content data files

Rationale: Move and sequence data is static content that changes infrequently. Storing it in TypeScript files provides:

  • Type safety
  • Easy content management
  • Offline availability
  • No API calls needed

Design

Decision: Dark mode as default

Rationale: Tai Chi is often practiced in calm environments. Dark mode reduces eye strain during video viewing and creates a more meditative atmosphere.

Decision: 400ms animation duration

Rationale: Standard Tai Chi movements are slow and flowing. App animations mirror this aesthetic. Faster animations feel jarring; slower feels sluggish. 400ms is the sweet spot.

Decision: No spring/bounce animations

Rationale: Bouncy animations break the zen atmosphere. All transitions use ease-out curves for smooth, natural movement.

Decision: Jade green (#4aa876) as primary accent

Rationale: Jade represents balance and harmony in Chinese culture. The specific hue (HSL 160, 45%, 45%) is calming without being too saturated.

Content

Decision: Placeholder videos from Pexels

Rationale: The app needs real video content to demonstrate the player functionality. Pexels provides royalty-free video that can be used for development. Production content must be replaced with properly licensed Tai Chi instruction.

Decision: Audio placeholders from Freesound

Rationale: Similar to video - demonstration requires real audio files. Production audio should be licensed appropriately.

Offline Support

Decision: PWA approach

Rationale: Service workers enable offline access without requiring app store distribution. Users can install the PWA to their home screen for an app-like experience.

Decision: Explicit download action required

Rationale: Video files are large. Automatic caching would consume user storage unexpectedly. Users explicitly choose what to download with clear file size indication.

Decision: 500MB storage warning threshold

Rationale: Mobile devices have limited storage. Warning at 400MB, hard limit at 500MB prevents the app from consuming excessive device space.

Privacy

Decision: No authentication required

Rationale: Friction-free onboarding is essential for a wellness app. Users should be able to start practicing immediately. All data is stored locally.

Decision: Session-based anonymous tracking

Rationale: A random session ID identifies the browser for progress tracking without any personal information.

Decision: Optional analytics with opt-out

Rationale: Analytics help improve the app but are not essential. Users can disable in settings. No PII is ever collected.

Future Considerations

  1. Cloud sync: If user accounts are added, progress could sync across devices
  2. Native apps: Expo version could be built from shared component library
  3. AI audio generation: If Suno or similar offers free API, ambient audio could be generated dynamically
  4. Community features: Sharing practice sessions, following instructors
  5. Premium content: Subscription for advanced sequences and personalized paths
