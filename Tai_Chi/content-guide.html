ZenFlow - Content Guide

This guide explains how to add, modify, and manage Tai Chi content in ZenFlow.

Video Content Requirements

Recording Guidelines

Resolution: 1920x1080 (1080p) minimum, 4K preferred Frame Rate: 30fps or 60fps Aspect Ratio: 16:9 (landscape) Duration: 30 seconds to 3 minutes per move Format: MP4 with H.264 codec (web-compatible)

Best Practices

  1. Lighting: Soft, even lighting. Avoid harsh shadows.
  2. Background: Simple, uncluttered. Neutral colors work best.
  3. Clothing: Loose, traditional Tai Chi attire preferred.
  4. Camera Position: Full body visible. Static camera, no panning.
  5. Multiple Angles: Consider front, side, and back views.
  6. Speed: Normal pace with option for slow-motion segments.

File Hosting

Videos can be hosted on:

  • CDN (recommended): Cloudflare R2, AWS S3, Vercel Blob
  • Video platforms: Mux, Cloudflare Stream
  • Self-hosted: Your own server with proper bandwidth

Replace placeholder URLs in src/data/moves.ts:

{
  id: 'move-001',
  name: 'Opening Form',
  videoUrl: 'https://your-cdn.com/videos/opening-form.mp4',
  thumbnailUrl: 'https://your-cdn.com/thumbnails/opening-form.jpg',
  // ...
}

Audio Content Requirements

Ambient Tracks

Format: MP3 or AAC Duration: 5+ minutes (will loop) Sample Rate: 44.1kHz or 48kHz Bitrate: 128kbps minimum, 256kbps preferred

Recommended Sources

  • Freesound.org - Creative Commons audio
  • Pixabay Music - Royalty-free tracks
  • Custom composition - Original ambient audio

Audio Types Needed

  1. Flowing Water - Stream, waterfall, rain sounds
  2. Forest - Birds, rustling leaves, gentle wind
  3. Tibetan Bowls - Singing bowls, meditation bells
  4. Wind - Gentle breeze, mountain wind
  5. Silence - No audio track

Update src/data/audio-tracks.ts:

{
  id: 'flowing-water',
  name: 'Flowing Stream',
  audioUrl: 'https://your-cdn.com/audio/flowing-water.mp3',
  // ...
}

Adding New Moves

Step 1: Prepare Content

  1. Record or source the video
  2. Create a thumbnail (16:9, 400px width minimum)
  3. Host files on CDN

Step 2: Add to Data File

Edit src/data/moves.ts:

export const moves: TaiChiMove[] = [
  // ... existing moves
  {
    id: 'move-013', // Unique ID
    name: 'Needle at Sea Bottom',
    chineseName: '海底针',
    description: 'A lowering movement where the body sinks...',
    breathingCue: 'Exhale as you lower, inhale as you rise.',
    mentalFocusCue: 'Imagine reaching down through deep water...',
    commonMistakes: [
      'Bending from the waist instead of the hips',
      'Letting the knee extend past the toes',
    ],
    difficulty: 'intermediate',
    durationSeconds: 45,
    benefits: ['Improves hip flexibility', 'Strengthens legs'],
    videoUrl: 'https://your-cdn.com/videos/needle-sea-bottom.mp4',
    thumbnailUrl: 'https://your-cdn.com/thumbnails/needle-sea-bottom.jpg',
    tags: ['yang-style', 'intermediate', 'lowering'],
  },
];

Step 3: Add to Sequences (Optional)

If the move belongs in a sequence, update src/data/sequences.ts:

{
  id: 'seq-003',
  name: 'Yang Style Essentials',
  moveIds: [
    'move-001',
    'move-002',
    // ... add your new move ID
    'move-013',
  ],
  // ...
}

export const sequences: TaiChiSequence[] = [

Licensing Requirements

Before Publishing

⚠️ All placeholder content must be replaced with properly licensed material.

Required licenses:

  • Video: Rights to use and distribute Tai Chi instruction
  • Audio: Royalty-free or Creative Commons (attribution if required)
  • Images: Rights for commercial/app usage

Recommended License Types

  • Royalty-free: One-time purchase, unlimited use
  • Creative Commons CC0: No attribution required
  • Creative Commons BY: Attribution required
  • Custom: Direct license from content creator

Attribution

If using CC-BY content, add attribution in docs/attributions.md and link from the Settings page.

Quality Checklist

Before adding content, verify:

  • Video plays smoothly on mobile
  • Audio loops seamlessly
  • Thumbnail clearly shows the move
  • Description is accurate and helpful
  • Breathing cues match the movement timing
  • Common mistakes are specific and actionable
  • Difficulty rating is appropriate
  • Tags enable logical filtering
  • All URLs are HTTPS
  • Files are optimized for web delivery
