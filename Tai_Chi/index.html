ZenFlow — Tai Chi Meditation & Learning

Learn Tai Chi at your own pace with guided video instruction and ambient meditation audio.

What is ZenFlow?

ZenFlow is a mobile-first web application for learning Tai Chi through organized video content, ambient meditation audio, and structured movement progressions. Users watch individual Tai Chi move clips and grouped sequences, accompanied by calming background music, to learn form, relax, and achieve mental clarity.

Who is it for?

  • Adults aged 25–65 who want to reduce stress and learn Tai Chi at home
  • People seeking flexible, self-paced instruction without fixed class schedules
  • Existing practitioners who want structured reference and meditation sessions
  • Anyone interested in mindful movement and wellness

Core Features

  • 📚 Move Library — Browse individual Tai Chi movements with detailed instruction
  • 🎬 Video Player — Full-screen playback with speed control and looping
  • 🎵 Ambient Audio — Flowing water, forest sounds, Tibetan bowls
  • 📖 Sequences — Curated collections of moves for complete practice
  • 🎯 Learning Paths — Structured progression for different goals
  • ⏱️ Timed Sessions — 5, 10, 20, or 30-minute guided practice
  • 📊 Progress Tracking — Track what you’ve watched (no account required)
  • 🌙 Dark Mode — Designed for meditation (dark mode is default)

Quick Start

Prerequisites

  • Node.js 20 or later
  • PostgreSQL 15 or later
  • npm or pnpm

Installation

# Clone the repository
git clone https://github.com/PlanExServices/Tai_Chi.git
cd Tai_Chi

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Edit .env with your database URL

# Push database schema
npx drizzle-kit push

# Start development server
npm run dev

# Open http://localhost:3000 in your browser.

Environment Variables

Required

DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db

Optional

NEXT_PUBLIC_POSTHOG_API_KEY=phc_xxx  # For analytics

Adding Your Own Content

The app ships with placeholder content for demonstration. Before publishing, replace with your own licensed Tai Chi videos and audio.

Videos

Edit src/data/moves.ts and add your video URLs and thumbnails.

Audio

Edit src/data/audio-tracks.ts and add your audio tracks.

Development

# Start development server
npm run dev

# Type check

# Build for production
npm run build

npm run start

npx drizzle-kit push

Deployment

Vercel (Recommended)

  1. Connect your GitHub repository to Vercel
  2. Add environment variables in Vercel dashboard
  3. Deploy

Other Platforms: AWS Amplify, Railway, Render, or self-hosted with Node.js.

Offline Support

ZenFlow is designed for offline use (PWA, content downloads, persistent progress). The PWA manifest is at public/manifest.json.

Design System

Colors and animation guidelines are described in the README. Font: Inter; Default dark background.

Known Limitations

  • Demo Content — All videos/audio are placeholders
  • No Sync — Progress is device-local only
  • No Offline Video — PWA caching not yet implemented
  • Single Language — English only

Troubleshooting

Video won’t play

  • Check that the video URL is HTTPS
  • Verify the format is MP4 with H.264 codec
  • Ensure CORS headers allow your domain

Database connection fails

# Check PostgreSQL is running
pg_isready -h localhost -p 5432

# Verify connection string in .env
echo $DATABASE_URL

Build fails

# Clear Next.js cache
rm -rf .next

# Reinstall dependencies
rm -rf node_modules
npm install

# Regenerate Tailwind styles
npm run build
